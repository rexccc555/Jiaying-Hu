# Take a Day Off · 小红书本机发布台

## 精简用法

1. 双击仓库根目录 **`发布到小红书.bat`**（黑窗口别关）  
2. 在网站规划行程 → 结果页点 **「发到小红书」**  
3. 会打开本机发布台，**文案已带好** → 拖入视频/图 → 登录 → 预览 → 确认发布  

第一次需：Python 3.10+（Add to PATH）、Google Chrome。

下载整仓：https://github.com/rexccc555/Jiaying-Hu/archive/refs/heads/main.zip  
本目录：`tools/cutpost`
